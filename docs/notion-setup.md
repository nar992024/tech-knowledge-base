# Notion 설정과 콘텐츠 운영

## 1. Integration 만들기

1. [Notion Integrations](https://www.notion.so/my-integrations)에서 Internal Integration을 만듭니다.
2. Capabilities에서 콘텐츠 읽기, 수정, 입력 권한을 켭니다. 사이트 운영만 하고 초기 입력을 끝냈다면 읽기 권한만 남겨도 됩니다.
3. 토큰을 `.env`의 `NOTION_API_KEY`에 넣습니다.

## 2. 데이터베이스 만들기

아래 필드 이름과 타입을 정확히 맞춰 데이터베이스 2개를 만듭니다. 입력 스크립트가 쓰기 전에 구조를 확인하므로, 다르면 아무것도 쓰지 않고 중단합니다.

### 코스 DB

| 필드      | 타입     |
| --------- | -------- |
| 코스명    | Title    |
| slug      | Text     |
| 순서      | Number   |
| 난이도    | Select   |
| 소개      | Text     |
| 대상      | Text     |
| 선수 지식 | Text     |
| 공개 여부 | Checkbox |

### 링크 DB

| 필드      | 타입                           |
| --------- | ------------------------------ |
| 제목      | Title                          |
| 링크 ID   | Text                           |
| URL       | URL                            |
| 목적      | Text                           |
| 카테고리  | Select                         |
| 유형      | Select                         |
| 검증 상태 | Select                         |
| 공개 여부 | Checkbox                       |
| 이용 조건 | Select                         |
| 코스      | Relation (코스 DB 연결, 1개만) |
| 순서      | Number                         |
| 난이도    | Select                         |
| 언어      | Select                         |
| 예상 시간 | Number                         |

Select 옵션은 입력 스크립트가 자동으로 만듭니다.

## 3. 연결과 환경 변수

1. 두 데이터베이스의 `...` → `Connections`에서 Integration을 연결합니다.
2. 데이터베이스 URL의 32자 ID를 `.env`에 넣습니다.

```env
NOTION_API_KEY=ntn_xxx
NOTION_DATABASE_ID=링크_DB_ID
NOTION_COURSE_DATABASE_ID=코스_DB_ID
```

## 4. 초기 데이터 입력

```bash
npm run notion:seed -- --dry-run   # 쓰지 않고 결과만 미리 보기
npm run notion:seed                # 없는 행만 추가
npm run notion:seed -- --update    # 기존 행도 data/seed.json 값으로 덮어쓰기
```

`--update`는 Notion에서 수정한 내용까지 덮어쓰므로 초기 입력을 다시 할 때만 사용합니다.

## 콘텐츠 운영

변경 내용은 최대 5분 안에 사이트에 반영됩니다.

| 작업        | 방법                                                                          |
| ----------- | ----------------------------------------------------------------------------- |
| 링크 추가   | 링크 DB에 행을 만들고 필수 필드를 채운 뒤 `공개 여부`를 체크합니다            |
| 코스에 넣기 | 원문을 확인해 `검증 완료`로 바꾸고 `코스`, `순서`, `난이도`를 입력합니다      |
| 코스 추가   | 코스 DB에 행을 만들어 내용을 채우고 링크를 연결한 뒤 `공개 여부`를 체크합니다 |
| 링크 숨기기 | 행을 지우지 않고 `공개 여부`를 해제합니다                                     |

### 공개 규칙

- 코스 단계에는 `공개 여부`를 체크하고 `검증 완료`인 링크만 표시합니다.
- 표시할 단계가 없는 코스는 공개로 설정해도 목록에 나오지 않습니다.
- 자료실에는 `공개 여부`를 체크한 링크를 모두 표시합니다.
- `목적`은 방문자에게 그대로 보이므로 내부 메모를 쓰지 않습니다.
- `slug`는 영문 소문자, 숫자, 하이픈만 사용합니다. 바꾸면 기존 코스 주소가 달라집니다.

### 입력 오류

필수 값이 없거나 URL이 잘못된 행, 코스를 연결했는데 순서나 난이도가 없는 행은 사이트에 표시하지 않고 서버 로그에 링크 ID를 남깁니다. 새 링크가 보이지 않으면 이 조건을 먼저 확인합니다.
